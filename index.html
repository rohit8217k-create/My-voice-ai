अपनी आवाज़ • अपनी स्क्रिप्ट

यह My Voice AI है। आपकी पहले से क्लोन की गई आवाज़ बैकएंड में Voice ID के ज़रिए इस्तेमाल होगी। API key सुरक्षित रूप से सर्वर पर रखी जाएगी।
STEP 01

क्लोन की गई आवाज़

आपकी Voice ID सर्वर पर सेट की जाएगी। हर बार सैंपल अपलोड करने की ज़रूरत नहीं है।

Voice ID बैकएंड की Environment Variables में सेट करें।
STEP 02

हिंदी टेक्स्ट लिखें

अपनी वीडियो स्क्रिप्ट यहाँ पेस्ट करें।

0/5000 अक्षर
STEP 03

आवाज़ जनरेट करें

आपका टेक्स्ट Fish Audio API को भेजा जाएगा और MP3 ऑडियो वापस मिलेगा।

टेक्स्ट लिखकर आवाज़ बनाएं।
